ארמית: מסכת שבת, גרסת דפדפן

הקבצים כאן הם האפליקציה כולה. אין בה שום פנייה לאתר אחר, והיא עובדת בלי רשת אחרי הכניסה הראשונה.

פרסום ב-GitHub Pages, בכתובת
https://neriatsaf.github.io/aramit-shabbat-web/

1. ב-GitHub יוצרים מאגר ציבורי חדש בשם aramit-shabbat-web.
2. מעלים אליו את כל הקבצים והתיקיות שבקובץ הזה, כך שהקובץ index.html יהיה בתיקייה הראשית של המאגר.
   יש להעלות גם את הקובץ .nojekyll.
3. בהגדרות המאגר, תחת Pages, בוחרים את הענף main ואת התיקייה הראשית, ושומרים.
4. אחרי דקה או שתיים האפליקציה זמינה בכתובת שלמעלה.

עדכון לגרסה חדשה: מעלים את הקבצים החדשים במקום הישנים. המכשירים מקבלים את הגרסה החדשה בכניסה הבאה.

חשוב: את קובץ החתימה של האפליקציה לאנדרואיד ואת הסיסמה שלו אין להעלות למאגר הזה, כי הוא ציבורי.
